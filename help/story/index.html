インスタのストーリーズ用の画像は、Mac で作って、アプリに並べてあります。
バグるは、その画像から毎日自動で投稿しています。 ストーリーズ作成のアプリは、手で投稿したいときに画像を選んで保存するためのものです。

  • 1はじめに開きかた

  • 3自動投稿毎日10時台と17時台
  • 4画像を作り直すMac でやること
  • 5困ったときLINE の知らせ
1

はじめに

開きかた

オーナー（T3 Owner）の画面の「📸 ストーリーズ作成」を押します。 合言葉は聞かれません。「🏠 ホーム」で、オーナーの画面に戻ります。

ホーム画面に置くのは、オーナーだけで大丈夫です（マインの使い方 1番（はじめに））。
2

画像を保存する

保存のしかた

  1. 「店舗を選んでください」で、店舗を押します
  2. 画像が並びます。使いたい画像を押します
  3. 画像が大きく出ます。画像を長押しして［写真に保存］を選びます
  4. インスタのアプリで、保存した画像をストーリーズに投稿します

パソコンのときは、画像の下の「パソコンならこちら（ダウンロード）」で保存できます。

「‹ 他の画像を選ぶ」「‹ 店舗を選びなおす」で戻れます。

画像の並びと札

  1. その日のイベント（肉の日など）の画像が、一番上に来ます
  2. 次に、期間限定・まとめ・おやすみ（「本日定休日です」など）の画像が来ます
  3. そのあとに、他の画像が並びます

画像には、区分（紫）・イベント（赤）・テイクアウト（緑）の札が付きます。毎月29日（2月は9日）は、店舗の横に「きょうは肉の日」と出ます。

手で投稿したとき

手で投稿した分は、自動投稿は知りません。同じ日に、同じ画像が自動でも出ることがあります。 バグるで手で投稿するときは、気をつけてください。

3

自動投稿

何が出るか

  • バグる 毎日10時台と17時台に1枚ずつ（1日2枚）、アプリに並んでいる画像から自動で投稿します。普段は何もしなくて大丈夫です。
  • popo 自動投稿はしていません。投稿するときは、2番（画像を保存する）のとおり手で投稿します。

画像の選ばれかた

  1. 一度出した画像は、14日のあいだ出しません
  2. 期間限定の画像は、毎日1枚出します
  3. イベントの日（肉の日など）は、イベントの画像から出します

定休日と臨時休業の日

マネージの定休日・臨時休業の設定を見て、朝に「本日定休日です」「本日臨時休業です」を1枚出します。夕方は出しません。

臨時休業・臨時営業は、その日の朝10時より前にマネージに入れておいてください（10時15分ごろに読みます）。
その日に「⚠️ インスタの自動投稿を始められませんでした」の LINE が来たときは、休みの知らせが出ないことがあります。 そのときは、ストーリーズ作成のアプリの「本日臨時休業です」を、手で投稿してください。
4

画像を作り直す

画像は Mac で作ります。T3Works フォルダーの「ダブルクリック」の中のファイルを、ダブルクリックして使います。 黒い画面が出ますが、閉じずに待ってください。何かを打つ必要はありません。最後に「何かキーを押すと閉じます」と出たら、終わりです。

ストーリーズ画像を作り直す

値段・文言・営業時間・写真・デザインを変えたあとに使います。数分かかります。

  1. 「▶ 1/2 画像を作っています」… 全部の画像を作り直します
  2. 「▶ 2/2 アプリとインスタに反映しています」… アプリに並べ、次の自動投稿から新しい画像になります
  3. 「おわりました」と出たら終わりです。アプリが古いままなら、開き直してください
「✖ 画像づくりでつまずきました」「✖ 反映でつまずきました」と出たら、その画面をそのままコピーして知らせてください。
「他の分野の直しが混ざっています」と出たときは、画像はもうできています。そのまま知らせてください。
インスタは公開した画像を読みに来るので、作り直すのは10時・17時の少し前を避けてください。

素材から台紙を作る

Canva で作った飾りを、T3Works フォルダーの「story」→「素材」→ 店舗のフォルダに入れたあとに使います。 ファイルの名前の頭（全面_・上帯_・下帯_・左上_・右上_・左下_・右下_）で、飾りを置く場所が決まります。頭が無いファイルは使いません。

終わると、見くらべのページができます。ここではまだ、お店に出る画像は変わっていません。 見くらべて良ければ知らせてください。本番に入れます。

5

困ったとき

LINE に知らせが来た

自動投稿がうまくいっている日は、何も来ません。来たときは、次のどれかです。

  • ⚠️ インスタの自動投稿が止まっています その日の枚数が足りません。店ごとに「◯枚（◯枚のはず）」と出ます。知らせの中の GitHub の画面から、手で動かせます。分からなければ、アプリを直す人に頼んでください。
  • ⚠️ 休みの日なのに、インスタに2枚以上出ています 休みの日は「本日定休日です」「本日臨時休業です」の1枚だけのはずです。Instagram で確かめて、要らない投稿は消してください。
  • ⚠️ インスタ自動投稿の記録が読めませんでした 公開が止まっているかもしれません。アプリを直す人に知らせてください。
  • ⚠️ インスタの自動投稿を始められませんでした GitHub のトークンが切れているかもしれません。アプリを直す人に知らせてください。
  • 🔑 GitHubのトークンが、あと◯日で切れます 切れる30日前から来ます。入れ直し方は、T3Works フォルダーの「引き継ぎ.md」の4番にあります。

アプリに「うまくいきませんでした。」と出る

画像の一覧を読めなかったときです。電波を確かめて、開き直してください。続くときは、アプリを直す人に知らせてください。

新しい画像が出てこない

このアプリには「新しい版があります」の知らせがありません。アプリを閉じて、開き直してください。

T3 Works は、6店舗の閉店作業・掃除・教育・シフトを、みんなの端末で同じように見るためのアプリです。 入力したものは、他の人の端末にも届きます。
はじめて使う人は 1 番から、困ったときは 11 番から読んでください。
数字が3つ出てきます（合言葉・あなたの番号・シフトの番号）。取りちがえやすいので、1番の表で見くらべてください。

  • 1はじめにホーム画面・合言葉・番号
  • 2クローズ毎日やります
  • 3ジャーナル撮って、日報に書く
  • 4週間掃除2週間ごと
  • 5教育新しく入った人に
  • 6シフト希望を出す・組む
  • 7記録を見るあとから見る
  • 8お金まわり立て替え・キャッチ
  • 9面接マニュアル面接で聞くこと
  • 10QRコード・URLアプリを人に渡す
  • 11困ったときよくある3つ

はじめに

これは何のアプリですか

お店を閉めるときの確認や、掃除の記録をつけるためのものです。 紙のチェック表を、スマホでやるようにしたものと思ってください。

紙とちがうのは、入力したものが、他の人のスマホにも出るところです。 「昨日ちゃんと閉めたか」を、他の店にいても見られます。

ホーム画面に置く（はじめの1回だけ）

URLをもらったら、まずホーム画面に置いてください。 次からは、アイコンを押すだけで開きます。

（URLを渡す側の人は、10番の「QRコード・URL」を使います）

iPhone で Safari を使うとき（おすすめ）

  1. もらったURLを Safari で開きます
  2. アドレス欄（URLが出ている所）の横の「⋯」を押して、「共有」を押します。
    「⋯」が無いときは、画面の下か上にある四角から矢印が上に出ている印を押します
  3. 出てきた一覧を指ですべらせて、「ホーム画面に追加」を押します
  4. 「Webアプリとして開く」が出ていたら、オンのままにします
  5. 右上の「追加」を押します

iPhone で Chrome を使うとき

  1. もらったURLを Chrome で開きます
  2. アドレス欄の右にある四角から矢印が上に出ている印（共有）を押します。 見当たらないときは「⋯」→「共有」
  3. 一覧を指ですべらせて、「ホーム画面に追加」を押します
  4. 「追加」を押します
Chrome の一覧に「ホーム画面に追加」が無いときは、iPhone が古いため（iOS 16.3 まで）です。 URLをコピーして Safari に貼って開き、上の Safari の手順で置いてください。 iOS の版は「設定」→「一般」→「情報」で見られます。

Android のとき

  1. もらったURLを Chrome で開きます
  2. 右上の点が3つ縦に並んだ印（⋮）を押します
  3. 「ホーム画面に追加」を押します。 版によっては「アプリをインストール」や「インストールしてショートカットを作成」という名前です
  4. 「インストール」か「追加」を押します
iPhone では、ホーム画面から初めて開いたときに、合言葉と番号をもう一度聞かれることがあります。 ホーム画面のアイコンは、Safari や Chrome とは別に覚えるためです。1回入れれば、次からは聞かれません。
なぜ置くのか。毎回URLを打たなくてよくなります。 それに、ホーム画面から開くと画面が広く使えて、文字も大きく見えます。
ブラウザのまま使っていると、しばらく開かないあいだに、入れた合言葉や番号が消えることがあります。 ホーム画面から開けば消えません。

合言葉（PIN）と、あなたの番号を入れる

はじめて開くと、この画面が出ます。上の欄が合言葉、下の欄が「あなたの番号」です。 どちらも入れないと使えません。番号をまだ渡されていないときは、こうだいに聞いてください。

合言葉（PIN）を入力してください

全店舗で共有しているデータを開くために必要です。
一度入力すれば、この端末では次回から不要です。

マネージで作った、あなただけの番号です。分からないときは、こうだいに聞いてください。

合言葉と番号を入れて「開く」を押します。どちらも要ります。

入れるのは1回だけです。次からは聞かれません。 数字が見えているか不安なときは、右の「表示」を押すと出ます。

合言葉を入れないと

他の人が入力したものが見られません。自分が入力したものも、他の人に届きません。

合言葉が分からない・入れても通らないとき。こうだいに聞いてください。 何度もまちがえると、しばらく開けなくなることがあります。 10分ほど待ってから、もう一度ためしてください。

あなたの番号とは

6桁の数字で、1人に1つです。こうだいから渡されます。

入れると、画面の上に自分の名前が出ます。 「〇〇さんのアカウント」と出ていれば、正しく入っています。

名前が出ないときは、番号が入っていないか、違っているかもしれません。 「⚙ 設定」の「番号」で、今どの番号が入っているかを見られます。 違っていたら、その下の「番号を入れる」で入れ直してください。

なぜ要るのか。誰が入力したかが分かるようにするためです。 合言葉だけだと、6店舗の誰が入れたのか分かりません。

番号は人に教えないでください

番号で「あなた」が決まります。人に教えると、その人があなたとして入力できてしまいます。 合言葉はみんな同じですが、番号は1人ずつ違います。

「この番号は登録されていません」「この番号は使えません」と出たときは、 番号が違うか、登録されていません。渡された6桁を見直して、もう一度入れてください。 それでも出るときは、こうだいに聞いてください。
番号の画面が出ないまま、画面の上の印が赤くなるときは、アプリが古いままです。 「新しい版があります」と出ていれば押してください。出ていなければ、アプリを一度閉じて開き直します （11番の「困ったとき」にも書いてあります）。

数字が3つ出てきます。混ざらないように

使う場所がそれぞれ違います。

何の数字か どこで使うか 1人ずつ？
合言葉（PIN） このアプリを開くとき みんな同じ
あなたの番号 このアプリ（合言葉の下の欄） 1人ずつ違う
シフトの番号 シフト提出のページ（6番） 1人ずつ違う
★「あなたの番号」と「シフトの番号」は別の数字です。 取りちがえると入れません。シフトの番号でこのアプリには入れませんし、 その逆もできません。わざと分けてあります。

クローズ

お店を閉めるときの確認です。毎日やります。 やることは4つだけです。チェックする、担当者を選ぶ、申し送りを書く、提出する。

1）お店を選ぶ

アプリを開くと、お店が並んでいます。自分がいるお店を押してください。

T3 Works

名前の下の札で、今日の分が出してあるかが分かります。 赤い「未提出」は、まだ出ていません。緑の「提出済み」は、もう出ています。

2）「クローズ」を押す

お店を選ぶと、やることが並びます。クローズを押してください。

お店によって、並ぶものが少しちがいます。

3）やったものにチェックを入れる

やることが上から並んでいます。終わったものの四角を押してください。 緑のチェックが付きます。

ホール

1 / 2
テーブルを拭く

調味料の下も

21:40
床を掃く

押すと、その場でチェックが入ります。入れた時刻が、右に小さく出ます。

まちがえたときは、もう一度押します。「チェックを外す」の確かめが出るので、押すと外れます。

提出したあとに外すと

「この日は提出済みのため、提出も取り消されます」と出ます。外したら、もう一度提出してください。

押す場所は、四角でも文字でもかまいません。どちらを押してもチェックが入ります。 指が少しずれても入るように、四角のまわりは広めにしてあります。

4）担当者を選ぶ

日付の下に「担当者」があります。その日やった人の名前を選んでください。 選ばないと提出できません。

担当者

まだ選んでいないときは、赤い枠になります。

5）申し送りを書く（あれば）

次の日の人に伝えたいことがあれば書きます。無ければ空のままでかまいません。 「醤油が残り1本」「トイレの電球が切れた」のような、短い一言で足ります。

6）提出する

全部チェックが終わったら、一番下の「提出する」を押します。

全部そろいました

押すと「提出済み」に変わります。

ここが一番大事です

チェックを入れただけでは、提出したことになりません。 最後に「提出する」を押してください。 押さないと、他の人の画面では「未提出」のままです。

途中で閉じても消えません。チェックは押したその場で残ります。 続きは、あとから開いてやれます。
全部チェックしないと、提出のボタンは押せません。 残っているあいだは「未チェックが残り◯項目あります」と出ます。担当者も選んでください。
できなかった項目があるときは

やっていないものに、チェックを入れないでください。 全部やってから提出します。

できないまま締め切りを過ぎると、下のとおり知らせが飛びます。 それが「まだできていない」の合図になります。隠さなくて大丈夫です。

できなかったことは、申し送りに書いておいてください。 提出していなくても、書いたその場で他の人に届きます。 記録にも、何が残っているかと一緒に残ります。

出さないと、知らせが飛びます

その日の分が出ていないと、会社のグループLINEに知らせが届きます。締め切りはお店で違います。

  • こじゃれ・炭まろ・ちゃこる … 深夜2時まで
  • popo … 深夜2時まで（金・土だけ翌朝5時）
  • おいでんテラス … 深夜1時まで
  • バグる … 23時30分まで

過ぎてから少しして（ふつうは15分ほど）、まだ出ていないお店の分が飛びます。 ふつうは1回だけです。

定休日には飛びません。

この時刻は閉店の時刻ではありません。クローズの確認を出す締め切りで、閉店より後ろに取ってあります。

ジャーナル

閉店のときにレジから出るジャーナル（売上の紙）を撮ると、アプリが数を読み取って、日報に書きます。 毎日やります。

やることは6つです。出前館などを入れる、撮る、紙と見くらべる、違う数を直す、担当者を選ぶ、日報に書く。

1）「ジャーナル」を開く

お店を選んで、ジャーナルを押します。今日の日付で開きます。前の日の分は、画面の下の日付を押します。

「本日 まだ」なら、今日の分はまだ記録されていません。

2）ジャーナルを撮る

「📷 ジャーナルを撮る」を押すと、カメラが開きます。

ジャーナル

◯/◯（◯）
まだ撮っていません

一度撮ると、ボタンは「📷 撮り直す」に変わります。

撮るときは

どこまで写すかは、お店で違います。

  • 炭まろ・ちゃこる・バグる・popo … 「おつり」の行まで
  • こじゃれ … その日の「その他支払明細」に出ている項目まで
  • おいでんテラス … 紙の一番下まで

そこまでが切れていると、数を確かめられません。

綺麗に写すコツ
  • 紙が折れていたり、丸まっていたら、真っ直ぐに伸ばしてから撮ってください。折り目や曲がりのところは、文字が読めません
  • 明るいところで撮ってください。暗いと、文字を読みまちがえます
  • 発注書など、字の書いてあるものの上で撮らないでください。まわりの字まで読んでしまい、じゃまになります
  • なるべく真上から撮ってください。ななめだと行が曲がって、読み取れないことがあります

撮ると、アプリが読み取ります。「文字を読み取っています…」と出ているあいだは、終わるまで待ちます。 15秒を超えると「サーバーが混み合っています。このまま待ってください」と出ることがありますが、そのまま待ってください。

途中でアプリを閉じてしまっても、次に開いたときに続きからやり直します。

  • 打つのは紙の数です。出前館などを引くのは、アプリがやります
  • まちがえたときは、欄を空にすると読み取った数に戻ります
  • 表の現金売上と、下の「記録」の現金売上は同じ数です。どちらで直しても、もう片方にも入ります

桁をまちがえても、そのまま日報に入ります。打ったら、もう一度紙と見くらべてください。

商品券・ポイントの行は、人が入れます

レジの紙は「ポイント」「商品券」とまとめて出しますが、日報は種類ごとの行に分かれています。 紙からは分けられないので、その日に使われた分だけ、人が打ちます。 打ち方は4）と同じで、表のその行の欄を押して、テンキーで打つだけです。

  • 炭まろ・ちゃこる・popo・おいでんテラス … リクルートポイント／ぐるなびポイント／食べログポイント／西町商品券／プレミアム商品券／プレミアム商品券デジタル
  • バグる … おむすび商品券
  • こじゃれ … 打つ行はありません（紙に内わけが出るので、アプリが読みます）
  • 使われなかった日は、空のままにしてください。空の行は、日報に何も書きません
  • 0 も打たないでください。0 を打つと、日報に先に入っている数を消してしまいます
  • 空でも赤くなりません。読めなかった欄の赤い「—」とは別ものです
売掛（掛売）は、アプリが紙から読んで日報の「売掛金」に書きます。打つ必要はありません（0円の日は書きません）。

出前館・ウーバー・ロケットナウを入れます

ジャーナルの紙に出ない分です。写真の下の「日報に入れる」にある欄へ、 その日にあった分だけ入れます。無い日は空のままで大丈夫です。

こじゃれは入れなくて大丈夫です。こじゃれの紙は出前館とウーバーを分けて出すので、アプリが読みます。

ジャーナルに出ない分だけ入れてください。無い日は空のままで大丈夫です。

  • 何回かに分かれているときは、「=◯◯◯+◯◯◯」のように式で入れられます。日報にも式のまま入ります
  • スマホでは数字のボタンが出ます。「確定」で次の欄へ、「閉じる」でしまいます
  • 数字のボタンの上に、オレンジの枠と「★式の途中に入ります」が出ているときは、打つ場所が式の途中です。最後に打つときは、式の一番うしろを触ってください

仕入を入れます

同じ「日報に入れる」の中にあります。その下に日報の仕入先が並びますので、仕入先ごとに入れてください。

  • 灰色で「日報が計算」と出ている欄は打てません。日報の方で出る数です
  • 仕入先が出ていないときは、「日報から仕入先を読む」を押します
  • ここも式で入れられます（「=◯◯◯+◯◯◯」）

人件費を入れます

仕入の下にあります。入れ方は仕入と同じです。 その日にあった分だけ入れて、無い日は空のままにしてください。

入れた数は、そのつど日報に書かなくても残ります

ここまでで入れた数（直した数・商品券・ポイント・出前館・ウーバー・ロケットナウ・仕入・人件費）は、 打ったそばからアプリに保存されます。

  • 「記録する」も「日報に書く」も、そのつど押さなくて大丈夫です
  • 他のページへ行っても、アプリを閉じても消えません
  • あとから同じ日を開くと、続きから入れられます

日報に入るのは、下の「日報に書く」を押したときだけです。 入れ終わったら、忘れずに押してください。

5）担当者を選んで、日報に書く

  1. 下の「記録」の担当者で、名前を選びます（選ばないと書けません）
  2. 「ジャーナルの5つを日報に書く」を押します。このボタンは、書ける数がそろうと出ます
  3. 確かめの画面が出ます。並んだ数を紙と見くらべてから「書く」を押します

確認

◯◯◯　◯日のページ（ジャーナルの5つ・出前館・ウーバー・ロケットナウ・仕入明細・人件費）

現金売上 ◯◯,◯◯◯／クレジット ◯◯,◯◯◯／純売上 ◯◯,◯◯◯／当日客数 ◯◯（手で直した数）　※日報にすでにちがう数が入っていれば、書く前にもう一度聞きます

手で直した数には「（手で直した数）」と付きます。

このボタン1つで、記録（現金売上）も、出前館など・仕入・人件費も、まとめて日報に書きます。
押すと数秒で「記録しました。日報にはこのあと書きます…」と出て、画面が空きます。 日報に書き終わるのを待ちません。仕入・人件費・デリバリーも同じで、「◯◯は、このあと日報に書きます…」と出ます。

ここが楽になりました

「書きました」が出る前にアプリを閉じてもかまいません。日報に書くのは、サーバーが続けてくれます。 次に開いたときに、結果が出ます。

6）書いたあとの知らせを見る

表の下に、結果が出ます。書けるまでに、少し時間がかかることがあります。

ジャーナルを日報に書きました　→ ◯◯◯◯_日報　◯日　検算OK：当日総合計 ◯◯◯,◯◯◯ ＝ ジャーナルの売上

  • 検算OK 日報の合計と、紙の売上が合っています。これで終わりです。
  • 日報には書きましたが、★検算が合いません 打ちまちがいか、読みちがいです。日報を開いて、紙と見くらべてください。分からないときは、こうだいに知らせてください。
  • 「日報に書きました」とだけ出たとき 紙の売上が読めなかった日は、合計の確かめが出ません。日報の当日総合計と、紙の売上を自分で見くらべてください。
  • ★日報にちがう数が入っているので、まだ書いていません 日報の数が、あとから直されています。下に出る「日報の数を見て決める」を押すと、 赤い「上書きして書く」の画面が出ます。押すと、日報の数がアプリの数に上書きされます。 分からないときは「キャンセル」を押して、こうだいに聞いてください。
  • ★日報に書けませんでした 下に出る「もう一度書く」を押します。同じ数をもう一度書くだけなので、何度押してもかまいません（すでに書けていれば、日報は変わりません）。

記録の欄が「✓ 記録済み」になっていれば、記録も終わっています。

撮り直しは、1日4回までにしてください

写真の読み取りには、月に1,000枚までという上限があります。6店舗で分け合っています。

  • 読めなかった数は、撮り直さずに手で直せます（4）を見てください）。そちらの方が確実で、枚数も増えません
  • 撮り直すのは、紙が切れている・ぶれているときだけにしてください

この番号について

アプリの合言葉（PIN）とは別のものです。1人に1つで、他の人には教えないでください。 番号で「誰の希望か」が決まるので、他の人の名前では出せません。

  1. 枠の名前はお店によってちがいます（立ち上げ・ランチ・ディナーなど）
  2. 枠を押すと「◯◯ は何時から？」と出ることがあります。入れる時刻を選んでください
  3. 出られない日は、何も押さずに飛ばします
  4. 出したあとでも、締め切りまでは直せます
こじゃれ・炭まろ・ちゃこる・おいでんテラスは、時と分を回して選びます。 はじめは「—」になっています。選ばないまま出すと「時刻を選んでいない日があります」と出て、出せません。 その日の時刻を選んでから、もう一度出すを押してください。
募集していないときは開けません。「今は募集していません」と出ます。 お店が募集をはじめると出せるようになります。

提出ページをホーム画面に置く（おすすめ）

提出ページは半月に1回しか開かないので、ホーム画面に置いておくと便利です。

LINEの中で開いたときは

LINEの中の画面では、番号を覚えられず、ホーム画面にも置けません。 URLをコピーして、Safari（Android は Chrome）に貼って開いてから、下の手順で置いてください。

iPhone で Safari を使うとき（おすすめ）

  1. 提出ページのURLを Safari で開きます
  2. アドレス欄（URLが出ている所）の横の「⋯」を押して、「共有」を押します。
    「⋯」が無いときは、画面の下か上にある四角から矢印が上に出ている印を押します
  3. 出てきた一覧を指ですべらせて、「ホーム画面に追加」を押します
  4. 「Webアプリとして開く」が出ていたら、オンのままにします
  5. 右上の「追加」を押します

iPhone で Chrome を使うとき

  1. 提出ページのURLを Chrome で開きます
  2. アドレス欄の右にある四角から矢印が上に出ている印（共有）を押します。 見当たらないときは「⋯」→「共有」
  3. 一覧を指ですべらせて、「ホーム画面に追加」を押します
  4. 「追加」を押します
Chrome の一覧に「ホーム画面に追加」が無いときは、iPhone が古いため（iOS 16.3 まで）です。 URLをコピーして Safari に貼って開き、上の Safari の手順で置いてください。 iOS の版は「設定」→「一般」→「情報」で見られます。

Android のとき

  1. 提出ページのURLを Chrome で開きます
  2. 右上の点が3つ縦に並んだ印（⋮）を押します
  3. 「ホーム画面に追加」を押します。 版によっては「アプリをインストール」や「インストールしてショートカットを作成」という名前です
  4. 「インストール」か「追加」を押します

QRコード・URL

人にアプリを渡すときに使います。相手のスマホのカメラで読み取ってもらうか、URLをコピーしてLINEで送ってください。

ワークス（アプリ）

アプリ本体です。開いたら、合言葉と、その人の番号を入れてもらいます。

スマホのカメラで読み取ると開きます。LINEで送るときは「URLをコピー」を押して貼ります。

合言葉と番号は、QRコードやURLとは別に伝えてください。

シフト提出

アルバイトがシフトの希望を出すページです。開いたら、その人のシフトの番号を入れてもらいます。

スマホのカメラで読み取ると開きます。LINEで送るときは「URLをコピー」を押して貼ります。

シフトの番号は、1人ずつ別に送ってください（アプリの番号とは別のものです）。

QRコードにもURLにも、合言葉や番号は入っていません。全員が同じものを使います。
URLはLINEの中ではなく、Safari（Android は Chrome）で開くようになっています。

  • その場で読み取ってもらう… 相手のスマホのカメラで、QRコードを読み取ってもらいます
  • LINEで送る… 「URLをコピー」を押して、LINEに貼って送ります。 このURLは、LINEの中ではなく Safari（Android は Chrome）で開くようになっています
  • コピーできないスマホでは、ボタンが「選んだURLを長押しでコピー」に変わります。URLを長押ししてコピーしてください
  • 閉じるときは、左上の「✕」を押します
合言葉と番号は、別に伝えてください

QRコードにもURLにも、合言葉や番号は入っていません。 ワークスの合言葉と番号、シフトの番号は、1人ずつ別に伝えます。アプリの番号とシフトの番号は別のものです（1番の表）。

受け取った人には、1番の「ホーム画面に置く」（シフトは6番）のとおり、ホーム画面に置いてもらってください。

困ったとき

他の人が入れたものが、自分の画面に出てこない

一番多い原因

アプリを閉じている、または他のアプリを開いている間です。
アプリが裏にいる間は、新しい内容を取りに行きません。

すぐ出したいとき。アプリを開いて、ヘッダーの丸い印を押してください。その場で取りに行きます。

開いたままにしているときは、押さなくても自動で届きます。かかる時間は、開いている画面で変わります。

  1. 今日のクローズを開いている … 8秒おきに取りに行きます（10分さわっていなければ60秒おき。さわると8秒おきに戻ります）
  2. 同じお店の他の誰かが、今まさに入力している … 3秒おきになります（届いてから40秒間）
  3. それ以外の画面（別の日、提出記録など） … 60秒おきです

なぜ毎秒にしないのか。6店舗の端末が始終聞きに行くと、サーバーが1日に受けられる回数を 使い切ってしまい、誰も同期できなくなります。 「同じお店の誰かが今入力している」間だけ速くする、という配り方にしています。

それでも出てこないとき。入れた人の端末で、まだ送れていないことがあります。 その人の画面のヘッダーが ↑（まだ送れていない分があります）になっていないか、 見てもらってください。

同期の印が、ずっと回っている

一番多い原因

送っている最中です。1分から2分は、正常の範囲です。

印が回っているのは、次のどちらかです。どちらも入力は端末に残っていて、消えません。

  1. 送っています … 返事を待っています。返事が来ないときは、最大35秒待ってあきらめます
  2. 静かに送り直しています … 1回通らなかったので、3秒・6秒・12秒と間を空けて、黙って送り直しています

2 は、通らなかったことをいちいち赤で出さないための動きです。 送り直して通れば、何ごともなかったように ✓ に変わります。 この間も印は回ったままなので、続けて見ると「ずっと回っている」ように見えます。

2分を超えて回り続けるとき。次の順で試してください。

  1. 電波が届いているか見る（他のアプリが開けるか）
  2. アプリをいったん閉じて、開き直す
  3. それでも続くなら、設定の「赤くなった記録」を開いて、日時と理由をこうだいに伝える

「つながりません」「送れていません」と出る

まず知っておいてください

どの理由で出ていても、入力した内容が消えることはありません。 つながり次第、自動で送られます。

赤い帯に理由が出ます。やることが理由ごとに違います。

  • 電波が届いていません 電波の問題です。つながる場所へ移れば、自動で送られます。
  • サーバーが返事をしません 混み合っています。電波の問題ではありません。待っていると自動で送り直します。
  • サーバー側で結果を受け取れませんでした サーバーの中で止まっています。こちらのアプリも電波も悪くありません。自動で送り直します。
  • 今日の上限に達しました 今日の同期の回数を使い切りました。朝9時に戻り、自動で送られます。それまで入力は端末に残り、消えません。めったに出ないので、出たらこうだいに伝えてください。
  • 合言葉（PIN）が違います これだけは自分で直します。設定の「PINを入れ直す」から、正しい合言葉を入れてください。何度も試さないでください。10分のあいだに10回まちがえると、全部のお店のアプリが約10分、同期できなくなります（「PINの入力を続けて間違えたため、しばらく受け付けません（約10分）」）。分からないときは、こうだいに聞いてください。

何度も続けて出るとき。お店のやり方が悪いのでも、電波が悪いのでもありません。 アプリは黙って3回送り直すようにしてあるので、たいていはそのまま通ります。 続くときは、設定の「赤くなった記録」を開いて、日時と理由をこうだいに伝えてください。

ジャーナルの「混み合っています」は別のものです。 写真を読み取っているときは「サーバーが混み合っています」、日報に書くのを待っているときは「Google が混み合っています」と出ます。 そちらで出たときは、3番のとおり、閉じずにそのまま待ってください。

ヘッダーの印の見かた

画面の右上にある丸い印が、今どうなっているかを表しています。押すと、その場で同期します。

  • ✓ 同期できています 入力した内容が、みんなの端末に届いています。
  • 回っている印 … 送っています 少し待つと ✓ に変わります。静かに送り直している最中も、この印です。
  • ↑ まだ送れていない分があります つながり次第、自動で送られます。入力した内容が消えることはありません。
  • ! 送れていません 3回送り直しても通らなかったときです。理由は赤い帯に出ます。上の3つを見てください。

「新しい版があります」と出たら

画面の下に青い帯で出ます。押して更新してください。 直したところが、その端末にも入ります。押さないと古い画面のままです。
